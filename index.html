Versión 1.3 · Encuadre automático y diagnóstico

Haz una foto. Intentaré reconocer el alimento automáticamente y estimar sus calorías.

Selecciona una foto para comenzar. Para reconocerla necesitas internet y abrir la app desde HTTPS.

Las calorías son aproximadas para una porción de referencia; la foto no permite medir el peso. Se analizan varios encuadres para reducir la influencia del fondo, pero el modelo general puede confundir incluso frutas. Si no reconoce, muestra las categorías detectadas para diagnóstico. La imagen se analiza en tu dispositivo y no se sube a nuestro servidor.
